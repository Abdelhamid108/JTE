# Terraform Library (`terraform`)

The `terraform` library provisions and manages cloud infrastructure using HashiCorp Terraform with embedded Checkov security scanning.

---

## 1. Configuration Schema (`library_config.groovy`)

```groovy
fields {
    optional {
        infra_dir          = String   // Directory containing .tf files (default: "infra")
        tf_vars            = String   // Jenkins Secret file credential ID containing .tfvars
        install_tools      = Boolean  // Automatically install Checkov (default: false)
        softFail           = Boolean  // Checkov soft-fail mode (default: false)
        target_environment = String   // Environment tag (e.g. "prod")
        component_name     = String   // Component identifier
        inventory_file     = String   // Ansible inventory file written by Terraform
    }
}
```

---

## 2. Steps Reference

### `init`
Initializes the Terraform working directory and backend.
- **Signature**: `void call(Map args = [:])`
- **Command**: `terraform init -reconfigure`.

---

### `validate`
Verifies Terraform formatting and configuration validity.
- **Signature**: `void call()`
- **Command**: `terraform fmt -check` and `terraform validate`.

---

### `checkov`
Executes Checkov static security analysis against Terraform code.
- **Signature**: `void call(Map args = [:])`
- **Environment**: Sets `env.SECURITY_POLICY_PASSED = 'true'`.

---

### `plan`
Generates a binary execution plan (`tfplan`) and archives it as a Jenkins artifact.
- **Signature**: `void call(Map args = [:])`
- **Command**: `terraform plan -out=tfplan`.

---

### `deploy`
Applies the archived speculative binary plan.
- **Signature**: `void call(Map args = [:])`
- **Command**: `terraform apply tfplan`.

---

### `destroy`
Tears down infrastructure resources managed by the state.
- **Signature**: `void call(Map args = [:])`
- **Command**: `terraform destroy -auto-approve`.

---

### `approval`
Manual interactive confirmation gate before executing apply or destroy.
- **Signature**: `void call(Map args = [:])`

---

### `checkoutCode`
Checks out infrastructure code repository.
- **Signature**: `void call()`

---

### `installTools`
Installs Checkov and runtime tools on the agent.
- **Signature**: `void call()`

---

### `archiveInventory`
Archives the Ansible `inventory.ini` generated by Terraform outputs as a build artifact.
- **Signature**: `void call()`

---

## 3. Pipeline Configuration Example

```groovy
libraries {
    terraform {
        infra_dir          = "infra"
        install_tools      = true
        softFail           = true
        tf_vars            = "petclinic-tfvars"
        target_environment = "prod"
        component_name     = "eks-cluster"
    }
}
